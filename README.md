# P2 - Library Management System

A Python-based Library Management System that manages books, book copies, and issue/return operations using Excel.

This is my second practical Python project as part of my journey into Data Analytics.

## Project Objective

The objective of this project is to create a simple system for managing library books and their availability instead of maintaining the records manually.

The system stores book information in an Excel file and keeps track of total, available, and issued copies.

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- OpenPyXL
- Microsoft Excel

## Features

- Add new books
- View all books
- Search books by ID or title
- Issue books
- Return books
- Increase or decrease book copies
- Track total, available, and issued copies
- Automatically save and update data in Excel
- Validates user input
- Formats the Excel worksheet
- Adds filters to the Excel data
- Freezes the header row
